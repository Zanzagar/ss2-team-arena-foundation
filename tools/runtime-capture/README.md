# Runtime-capture instrumentation (unvalidated)

`ss2-capture-wrapper.as` is the independently authored AS2 instrumentation
host for controlled licensed-build capture sessions. It is committed as a
draft specification: no AVM1-capable player or AS2 compiler is installed, so
it has never been compiled or executed, and no trace it emits may be trusted
until it is validated.

Validation gate (in order):

1. Explicit approval to install a local AVM1 player (Ruffle desktop
   preferred) — nothing is downloaded without sign-off.
2. Verify `Object.watch`, timeline-function wrapping, `loadMovieNum` level
   isolation, and the overlay controller instance path against that player.
3. The wrapper must reproduce the reference traces generated by
   `node tools/capture-session.mjs simulate` for a staged candidate scenario
   (identical apart from meta identity and any passive roll values) before a
   real capture counts as evidence.

The wrapper reads the installed SWF in place by `file:` URL, never copies or
patches it, and emits only the JSONL grammar documented in
`docs/integration/ss2-runtime-capture.md`.
